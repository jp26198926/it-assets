# Add Dynamic "View Ticket" Links to Email Templates

## Goal
Add clickable "View Ticket" buttons to all ticket-related email notifications so users can go directly from their inbox to the ticket detail page.

## Approach
Use `headers()` from `next/headers` to derive the base URL at call time (no new env var needed). Pass both `ticketId` (MongoDB `_id`) and `baseUrl` into each email function, then render an `<a>` button linking to `/tickets/{ticketId}`.

Since all 7 email functions are called fire-and-forget (`.catch(() => {})`), the `getBaseUrl()` call must happen **in the caller** (where the request context is guaranteed alive), not inside the email function itself.

## Files to Modify

### 1. `lib/services/ticket-service.ts`
- **Add** `import { headers } from "next/headers"` at top
- **Add** `getBaseUrl()` helper (reads `host` + `x-forwarded-proto` from request headers)
- **Modify 5 email functions** — add `ticketId: string` and `baseUrl: string` parameters:
  - `sendRequestorEmail` (line 211)
  - `sendAssigneeEmail` (line 266)
  - `sendTicketUpdatedEmail` (line 323)
  - `sendTicketStatusChangedEmail` (line 376)
  - `sendNewAssigneeEmail` (line 442)
- **Add button** to each template's HTML body (after the detail box, before the footer text):
  ```html
  <div style="text-align: center; margin: 25px 0;">
    <a href="${baseUrl}/tickets/${ticketId}"
       style="display: inline-block; background: #3b82f6; color: white;
              padding: 12px 24px; text-decoration: none; border-radius: 6px;
              font-weight: bold; font-size: 14px;">
      View Ticket
    </a>
  </div>
  ```
- **Modify 4 callers** — compute `const baseUrl = getBaseUrl()` before the fire-and-forget call, pass `ticket.id` and `baseUrl`:
  - `createTicket` (~line 703): `sendRequestorEmail` + `sendAssigneeEmail`
  - `updateTicketStatus` (~line 807): `sendTicketStatusChangedEmail`
  - `updateTicket` (~line 851): `sendTicketUpdatedEmail`
  - `reassignTicket` (~line 907): `sendNewAssigneeEmail`

### 2. `lib/services/ticket-comment-service.ts`
- **Add** `import { headers } from "next/headers"` at top
- **Add** `getBaseUrl()` helper (same pattern)
- **Modify** `sendCommentNotificationEmail` (line 70) — add `ticketId: string` and `baseUrl: string` params, add same button HTML
- **Modify 2 callers** (lines ~171 and ~186) — pass `data.ticket_id` and `getBaseUrl()`

## Link Format
- URL: `{protocol}://{host}/tickets/{mongoDbId}`
- Renders as a styled blue button centered in the email body
- Placed after the details box and before the footer timestamp

## Verification
1. Start dev server: `npm run dev`
2. Create a ticket (triggers `sendRequestorEmail` + `sendAssigneeEmail`) — check console logs or SMTP for HTML containing the link
3. Add a comment on a ticket — verify comment notification email contains the link
4. Change ticket status — verify status change email contains the link
5. Reassign a ticket — verify reassignment email contains the link
6. Click the link in a received email — should navigate to the correct ticket detail page
