# Real-Time Clock in Header & Sidebar

## Goal
Add a real-time clock display in the header and sidebar that shows the current date/time using the configured app timezone. This lets the user easily verify the timezone setting is working correctly.

## Files to Modify
- `components/layout/header.tsx` — Add clock between breadcrumb and user menu
- `components/layout/app-sidebar.tsx` — Add clock in sidebar header (below app name)

## Implementation

### Header (`components/layout/header.tsx`)
1. Import `formatInAppTimezone` from `@/lib/utils/timezone`
2. Import `getAppSettings` from `@/lib/actions/application-actions`
3. Add state: `const [appTimezone, setAppTimezone] = useState<string | null>(null)`
4. Add state: `const [now, setNow] = useState(new Date())`
5. Add useEffect to fetch app settings: `getAppSettings().then(s => setAppTimezone(s.timezone))`
6. Add useEffect with `setInterval` to update clock every second
7. Add clock display in header between breadcrumb and user dropdown — show time only (e.g. `02:30:45 PM`) in a subtle badge style

### Sidebar (`components/layout/app-sidebar.tsx`)
1. Import `formatInAppTimezone` from `@/lib/utils/timezone`
2. Add state: `const [now, setNow] = useState(new Date())`
3. Fetch timezone in existing `getAppSettings` useEffect: add `setAppTimezone(settings.timezone)`
4. Add useEffect with `setInterval` to update clock every second
5. Add clock display in `SidebarHeader` below the app name — show date and time (e.g. `Jul 25, 2026 · 02:30 PM`)

### Clock Display Pattern
- Header: compact time only, positioned after breadcrumb separator, before user menu
- Sidebar: date + time, positioned below app name in the header area
- Both use `formatInAppTimezone(now, formatString, appTimezone)` with `setInterval(() => setNow(new Date()), 1000)`
- Cleanup interval on unmount
