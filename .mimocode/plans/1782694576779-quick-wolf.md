# Plan: Fix Upload 500 Error + Defer Upload to Submit

## Problem 1: 500 on POST /api/tickets/upload
The `upload_stream` approach is failing. The codebase uses `cloudinary.uploader.upload(base64)` everywhere else and it works. Fix the API route to convert the incoming `File` buffer to a base64 data URI and use the same proven upload method.

**File:** `app/api/tickets/upload/route.ts`
- Replace `upload_stream` with `cloudinary.uploader.upload(dataUri)`
- Convert buffer to base64: `data:image/${mime};base64,${buffer.toString("base64")}`
- Extract MIME type from `file.type`

## Problem 2: Defer upload to Create Ticket click
Currently files upload immediately on selection. User wants them stored as `File` objects and uploaded only when submitting.

**File:** `components/modals/ticket-form-modal.tsx`
- Add `pendingFiles` state (`File[]`) to hold selected files before upload
- `handleFileUpload`: validate size, add to `pendingFiles` (no upload yet), show file name in UI
- `removeAttachment`: remove from `pendingFiles`
- `handleSubmit`: before calling `onSubmit`, loop through `pendingFiles`, upload each via `fetch("/api/tickets/upload")`, collect URLs, merge into `formData.attachments`
- Show pending file count/names in the attachments area
- `handleRichTextImageUpload` still uploads immediately (rich text needs the URL right away to embed)

**File:** `app/(dashboard)/tickets/[id]/page.tsx`
- Same pattern: `pendingFiles` state for reply attachments
- `handleAttachmentUpload`: add to `pendingFiles`, no upload
- `handleSubmitComment`: upload all pending files first, then create comment with URLs
- `handleRichTextImageUpload` still uploads immediately
