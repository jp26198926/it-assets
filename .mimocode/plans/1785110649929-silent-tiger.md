# Fix Timezone-Aware MongoDB Aggregation Grouping

## Problem
MongoDB aggregation queries in `ticket-report-service.ts` and `dashboard-service.ts` group dates using UTC instead of the app's configured timezone. A ticket created at 2:00 AM Manila time (UTC+8) = 6:00 PM UTC previous day, gets grouped under the wrong day/week/month.

## Scope
**2 files to modify**, 0 new files. The date range filtering in ticket-service, meeting-service, and meeting-action-item-service is already timezone-aware — no changes needed there.

---

## Changes

### 1. `lib/services/ticket-report-service.ts`

**1a. Daily aggregation (line 195)** — add `timezone` to `$dateToString`:
```diff
- _id: { $dateToString: { format: "%Y-%m-%d", date: "$created_at" } },
+ _id: { $dateToString: { format: "%Y-%m-%d", date: "$created_at", timezone: timezone || "UTC" } },
```

**1b. Monthly aggregation (line 226)** — same fix:
```diff
- _id: { $dateToString: { format: "%Y-%m", date: "$created_at" } },
+ _id: { $dateToString: { format: "%Y-%m", date: "$created_at", timezone: timezone || "UTC" } },
```

**1c. Weekly aggregation (lines 205–221)** — Replace `$year`/`$isoWeek` (which don't accept timezone) with `$dateToString` grouping by day, then merge into ISO weeks in JS:
- Change the aggregation to group by day string (same as daily) with timezone
- After aggregation, compute ISO week from each date string and merge counts

**1d. Weekly result mapping (lines 247–254)** — Replace `.map()` with JS logic that:
1. Parses each `_id` date string (e.g., `"2026-07-27"`)
2. Computes ISO week number (year + week)
3. Merges per-day buckets into per-week buckets using a Map
4. Sorts by week key and maps to `{ label, count, open, in_progress, resolved, closed }`

### 2. `lib/services/dashboard-service.ts`

**2a. Add import** (after line 4):
```typescript
import { getAppSettings } from "./application-service";
```

**2b. Fetch timezone** (after line 41, inside `getDashboardStats()`):
```typescript
const { timezone } = await getAppSettings();
const tz = timezone || "UTC";
```

**2c. Ticket trend aggregation (line 122)** — add timezone:
```diff
- _id: { $dateToString: { format: "%Y-%m-%d", date: "$created_at" } },
+ _id: { $dateToString: { format: "%Y-%m-%d", date: "$created_at", timezone: tz } },
```

## What stays unchanged
- `lib/utils/timezone.ts` — no changes needed
