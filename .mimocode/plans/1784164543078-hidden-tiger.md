# Fix: Comment Message Doubled in Ticket Print

## Problem
In `handlePrint`, each comment is rendered twice — once as stripped plain text (`<p>${text}</p>`) and once as the full HTML content (`${c.message.replace(...)}`). The plain text version loses line breaks (no enter keys), while the HTML version preserves them, causing the doubled output you see.

## Root Cause
`app/(dashboard)/tickets/[id]/page.tsx` lines 453-464:
```js
const text = (c.message.replace(/<[^>]*>/g, "") || "(no text)")  // plain text
  .replace(/</g, "&lt;")
  .replace(/>/g, "&gt;");
return `
  ...
  <div class="comment-body">
    <p>${text}</p>                                          ← redundant plain text
    ${c.message.replace(/<img.../gi, ...)}                  ← full HTML content
  </div>`;
```

## Fix
Remove the `text` variable (lines 453-455) and the `<p>${text}</p>` line (line 463), keeping only the full HTML render.

### File
`app/(dashboard)/tickets/[id]/page.tsx`

### Change
```js
// Before
const text = (c.message.replace(/<[^>]*>/g, "") || "(no text)")
  .replace(/</g, "&lt;")
  .replace(/>/g, "&gt;");
return `
  ...
  <div class="comment-body">
    <p>${text}</p>
    ${c.message.replace(/<img[^>]*src="([^"]*)"[^>]*>/gi, '<div class="comment-img"><img src="$1" /></div>')}
  </div>`;

// After
return `
  ...
  <div class="comment-body">
    ${c.message.replace(/<img[^>]*src="([^"]*)"[^>]*>/gi, '<div class="comment-img"><img src="$1" /></div>')}
  </div>`;
```
