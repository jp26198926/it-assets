# Plan: Add "Mark as Resolved" action to Tickets DataTable

## Goal
Add a "Mark as Resolved" action button to the ticket row actions dropdown in the `/tickets` datatable, matching the behavior of the "Mark as Resolved" button on `/tickets/[id]`.

## Behavior (matching detail page)
- **Visibility**: Only shown when `!ticket.deleted_at && ticket.status !== "Resolved" && ticket.status !== "Closed"`
- **Confirmation**: Opens a plain `AlertDialog` (no reason field) — *"Are you sure you want to mark this ticket as resolved? This will change the status to \"Resolved\"."*
- **Action**: Calls `updateTicket(ticket.id, { status: "Resolved" })` server action
- **After success**: Refreshes the ticket list, shows toast `"Ticket marked as resolved"`
