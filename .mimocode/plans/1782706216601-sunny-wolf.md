# Advanced Search — Category & Department Dropdowns

## Goal
Replace the Category ID and Department ID text inputs in the Advanced Search dialog with dropdown selects populated from the API. Both must be on the same row.

## Files to Modify

1. `components/data-table/ticket-advanced-search-dialog.tsx` — Accept `selectOptions` prop, replace text inputs with dropdowns
2. `components/data-table/ticket-data-table-toolbar.tsx` — Pass `selectOptions` through to the dialog
3. `components/data-table/ticket-data-table.tsx` — Accept and pass `selectOptions` prop
4. `app/(dashboard)/tickets/page.tsx` — Pass `selectOptions` to `TicketDataTable`

## Implementation

### 1. `ticket-advanced-search-dialog.tsx`
- Add `selectOptions` prop: `{ categories: { id: string; name: string }[]; departments: { id: string; name: string }[] }`
- Replace Category ID `<Input>` with `<select>` dropdown using `selectOptions.categories`
- Replace Department ID `<Input>` with `<select>` dropdown using `selectOptions.departments`
- Put both on same row: `<div className="grid grid-cols-2 gap-4">`
- Change filter key from `category_id` to `category_id` (already correct — it sends the selected ID)
- Department currently sends raw ID text; dropdown will send the selected ID

### 2. `ticket-data-table-toolbar.tsx`
- Add `selectOptions` prop to interface
- Pass to `<TicketAdvancedSearchDialog selectOptions={selectOptions} />`

### 3. `ticket-data-table.tsx`
- Add `selectOptions` prop to interface
- Pass to `<TicketDataTableToolbar selectOptions={selectOptions} />`

### 4. `page.tsx`
- Pass `selectOptions` to `<TicketDataTable selectOptions={selectOptions} />`

## Verification
1. `npm run dev`, open Advanced Search
2. Category and Department are dropdowns with options from DB
3. Both on same row
4. Selecting values and searching works correctly
5. `npm run lint` clean
