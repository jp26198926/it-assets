# Plan: Stock Models, Receiving Module, and Inventory Integration

## Overview
Create 4 new models (StockLevel, StockMovement, Receiving, ReceivingItem), full CRUD for Receiving and ReceivingItem, a receiving detail page with "Mark as Completed" (transactional) and "Print" functionality.

---

## Part 1: Models (4 files)

### 1a. `lib/db/models/stock-level.ts` + `lib/types/stock-level.ts`
- Fields: `item_id` (FK→Item, required), `location_id` (FK→Location, required), `qty` (Number, default 0)
- Compound unique index on `(item_id, location_id)`
- No base audit fields (inventory tracking record)

### 1b. `lib/db/models/stock-movement.ts` + `lib/types/stock-movement.ts`
- Fields: `date` (Date), `transaction_type` (enum RECEIVE/RELEASE), `item_id` (FK→Item), `location_id` (FK→Location), `qty` (Number), `reference_trans_id` (ObjectId), `reference_item_id` (ObjectId), `reference_description` (String), `remarks` (String)
- Indexes on item_id, location_id, date

### 1c. `lib/db/models/receiving.ts` + `lib/types/receiving.ts`
- Fields: `code` (String, unique, auto-generated "RCV00001"), `date_received` (Date, required), `supplier_id` (FK→Supplier), `po_number` (String), `invoice_number` (String), `remarks` (String), `status` (enum Active/Completed/Cancelled, default Active)
- Base audit fields included
- Indexes: code (unique), status, supplier_id

### 1d. `lib/db/models/receiving-item.ts` + `lib/types/receiving-item.ts`
- Fields: `code` (String, unique, auto "RI00001"), `receiving_id` (FK→Receiving, required), `item_id` (FK→Item), `qty` (Number), `unit_price` (Number), `total_cost` (Number, computed: qty * unit_price), `expiration_date` (Date), `remarks` (String), `storage_location_id` (FK→Location), `status` (enum Active/Completed/Cancelled, default Active)
- Base audit fields included
- Indexes: code (unique), receiving_id, item_id, status

## Part 4: "Mark as Completed" Transaction Logic

In `receiving-service.ts`, the `completeReceiving(id)` function:

```ts
import { startSession } from "@/lib/db/connection";

export async function completeReceiving(id: string): Promise<void> {
  const session = await startSession();
  session.startTransaction();
  try {
    // 1. Get receiving and its items
    const receiving = await ReceivingModel.findById(id).session(session);
    if (!receiving) throw new Error("Receiving not found");
    if (receiving.status !== "Active") throw new Error("Receiving is not Active");

    const items = await ReceivingItemModel.find({ receiving_id: id, status: "Active" }).session(session);
    if (items.length === 0) throw new Error("No active receiving items");

    // 2. Loop items and process each
    for (const item of items) {
      // a. Update item.stock += receivingItem.qty
      await ItemModel.findByIdAndUpdate(item.item_id, {
        $inc: { stock: item.qty }
      }).session(session);

      // b. Update or create StockLevel
      const existing = await StockLevelModel.findOne({
        item_id: item.item_id,
        location_id: item.storage_location_id
      }).session(session);

      if (existing) {
        await StockLevelModel.findByIdAndUpdate(existing._id, {
          $inc: { qty: item.qty }
        }).session(session);
      } else {
        await StockLevelModel.create([{
          item_id: item.item_id,
          location_id: item.storage_location_id,
          qty: item.qty
        }], { session });
      }

      // c. Create StockMovement record
      await StockMovementModel.create([{
        date: new Date(),
        transaction_type: "RECEIVE",
        item_id: item.item_id,
        location_id: item.storage_location_id,
        qty: item.qty,
        reference_trans_id: receiving._id,
        reference_item_id: item._id,
        reference_description: `${receiving.code} ${item.code}`,
      }], { session });

      // d. Update receiving item status to Completed
      await ReceivingItemModel.findByIdAndUpdate(item._id, {
        status: "Completed"
      }).session(session);
    }

    // 3. Update receiving status to Completed
    await ReceivingModel.findByIdAndUpdate(id, {
      status: "Completed",
      updated_at: new Date()
    }).session(session);

    await session.commitTransaction();
  } catch (error) {
    await session.abortTransaction();
    throw error;
  } finally {
    session.endSession();
  }
}
```

## Key Decisions (from user)
- **ReceivingItem delete**: Soft-delete (deleted_at field, can be restored)
- **StockLevel location**: Uses receivingItem.storage_location_id
- **Receiving cancel**: Only Active status can be cancelled (Completed is final)
