# Plan: Add Stock, Last Cost, Avg Cost Fields to Item Model

## Overview
Add three new numeric fields to the Item entity for tracking inventory: `stock`, `last_cost`, and `avg_cost`. These are manually editable for now, with potential auto-update from purchase transactions later.

---

## Files to Modify

### 1. `lib/db/models/item.ts` (Mongoose Schema)
Add fields to interface and schema:
```ts
// In IItem interface
stock: number;
last_cost: number;
avg_cost: number;

// In ItemSchema
stock: { type: Number, default: 0 },
last_cost: { type: Number, default: 0 },
avg_cost: { type: Number, default: 0 },
```

### 2. `lib/types/item.ts` (TypeScript Types)
Add to interfaces:
```ts
// In Item interface
stock: number;
last_cost: number;
avg_cost: number;

// In CreateItemInput
stock?: number;
last_cost?: number;
avg_cost?: number;
```

### 3. `lib/services/item-service.ts` (Service)
- Update `toItem()` mapper to include new fields
- Update `getItems()` to return new fields
- No filter changes needed yet

### 4. `components/modals/item-form-modal.tsx` (Form)
Add three number inputs in the form:
- Stock (number input, default 0)
- Last Cost (number input, default 0, allow decimals)
- Avg Cost (number input, default 0, allow decimals)

### 5. `components/data-table/item-data-table-columns.tsx` (Table Columns)
Add columns for:
- Stock
- Last Cost (formatted as currency)
- Avg Cost (formatted as currency)

### 6. `components/modals/item-view-modal.tsx` (View Modal)
Add display fields for:
- Stock
- Last Cost (formatted as currency)
- Avg Cost (formatted as currency)

### 7. `components/data-table/item-export-buttons.tsx` (Export)
Add columns to PDF and Excel exports:
- Stock
- Last Cost
- Avg Cost
