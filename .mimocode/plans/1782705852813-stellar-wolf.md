# Merge Ticket Title and Description Cards

## Change
Merge the two separate cards ("Ticket Header" and "Description + Attachments") into a single card on the ticket detail page.

## File
`app/(dashboard)/tickets/[id]/page.tsx`

## Current Structure (lines 914–968)
- **Card 1 — "Ticket Header"** (lines 915–931): title, contact name, email, time ago
- **Card 2 — "Description + Attachments"** (lines 933–968): description HTML + attachment list

## Target Structure
One card containing:
1. Title (`h2`)
2. Contact / email / time ago line
3. Description (`prose` div with `dangerouslySetInnerHTML`)
4. Attachments section (with `border-t` separator)

## Implementation
Delete the two separate `div.bg-white.shadow-sm.rounded-xl.p-6` wrappers and replace with a single one. Move the content from Card 2 inside Card 1, placing the description and attachments below the contact line.

## Verification
- Run `npm run dev` and navigate to a ticket detail page
- Confirm title, contact info, description, and attachments all appear in one card
- Check that the print layout (print-only section) is unaffected
