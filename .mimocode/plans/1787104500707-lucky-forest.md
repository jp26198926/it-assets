# Fix Duplicate Mongoose Schema Index Warnings

## Problem
Many Mongoose models define `unique: true` on field-level schema definitions, which automatically creates a unique index. Then the same fields also have explicit `Schema.index({ field: 1 }, { unique: true })` calls, creating duplicate indexes. Mongoose warns about this during build.

## Root Cause
When a field has `unique: true` in its schema definition, Mongoose automatically creates an index for it. Adding a separate `Schema.index()` for the same field creates a redundant duplicate.

## Fix Strategy
For each model, **remove the `Schema.index()` call** for fields that already have `unique: true` in the schema definition. Keep the `unique: true` on the field definition (it's more readable and co-located with the field). Keep non-unique `Schema.index()` calls (e.g., `{ status: 1 }`) as they are — those don't conflict.
