# Plan: Add Requestor Name column to ticket data table

## What
Add a "Requestor" column to the ticket data table that displays the ticket requestor's name.

## Current state
- The Requestor column already exists (added previously) using `requestor_name` (populated from User model)
- The user wants it to display the `name` field directly from the ticket document instead
- `Ticket` type has `name: string` (`lib/types/ticket.ts:4`) — this is the name field on the ticket itself

## Change
**File:** `components/data-table/ticket-data-table-columns.tsx`

Change `accessorKey` from `"requestor_name"` to `"name"` and simplify the cell renderer:

```tsx
{
  accessorKey: "name",
  header: ({ column }) => (
    <DataTableColumnHeader column={column} title="Requestor" />
  ),
  cell: ({ row }) => (
    <span className="text-sm text-[#1a1f36]">{row.getValue("name") || "N/A"}</span>
  ),
},
```

## Verification
1. Run `npm run build` or `npm run dev` to check for type errors
2. Navigate to `/tickets` page and confirm the Requestor column appears in the data table
3. Verify the requestor name renders correctly for tickets that have a `requestor_id` (populated user), and shows "N/A" for tickets without one
