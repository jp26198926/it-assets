# Plan: Add Advanced Search, Export, and Print to Stock Levels DataTable

## Context
The stock-levels module currently has a minimal read-only data table with no toolbar, no search, no export, and no print. This plan adds these three features following the established patterns from other modules (stock-movement, assets, tickets).

## Files to Modify
1. `components/data-table/stock-level-data-table-toolbar.tsx` — **NEW** toolbar component
2. `components/data-table/stock-level-data-table.tsx` — integrate toolbar + global filter
3. `app/(dashboard)/stock-levels/page.tsx` — pass search handlers to data table
4. `lib/types/stock-level.ts` — add `StockLevelFilters` type

## Files to Create
5. `components/data-table/stock-level-advanced-search-dialog.tsx` — advanced search dialog
6. `components/data-table/stock-level-export-buttons.tsx` — PDF + Excel export
7. `lib/utils/print-stock-level.ts` — print utility (opens new window with HTML)

---

## Step 1: Add `StockLevelFilters` to types

In `lib/types/stock-level.ts`, add:
```ts
export interface StockLevelFilters {
  item_name?: string;
  item_code?: string;
  location_name?: string;
  qty_min?: number;
  qty_max?: number;
}
```

## Step 2: Create `stock-level-advanced-search-dialog.tsx`

Follow the `stock-movement-advanced-search-dialog.tsx` pattern exactly:
- Props: `onSearch: (filters: StockLevelFilters) => void` and `onClear: () => void`
- Fields: Item Code (text), Item Name (text), Location (text), Qty Min (number), Qty Max (number)
- Dialog width: `max-w-lg`
- Same styling and structure as stock-movement version

## Step 3: Create `stock-level-export-buttons.tsx`

Follow the `stock-movement-export-buttons.tsx` pattern exactly:
- Props: `{ table: Table<StockLevel> }`
- Dynamic imports of `jspdf`, `jspdf-autotable`, `xlsx`
- PDF columns: Item Code, Item Name, Location, Quantity
- Excel columns: Item Code, Item Name, Location, Quantity
- DropdownMenu with PDF + Excel options
- Loading state with `useState<string | null>`

## Step 4: Create `print-stock-level.ts`

Follow the `print-transfer.ts` pattern:
- `export async function printStockLevels(levels: StockLevel[]): Promise<void>`
- Fetch `getAppSettings()` for company info
- Open new window, write full HTML with inline CSS
- Layout: company header → title "STOCK LEVELS REPORT" → table with all levels → footer
- Print button that calls `window.print()`
- `@media print` styles

## Step 5: Create `stock-level-data-table-toolbar.tsx`

Follow the `stock-movement-data-table-toolbar.tsx` pattern exactly:
- Props: `{ table, onServerSearch, onServerSearchClear, allData }`
- Row 1: filtered count display
- Row 2: search input + AdvancedSearchDialog + DataTableViewOptions + ExportButtons + Print button
- Permission-gated export via `useAuthorization()` with page path `/stock-levels`
- Print button: calls `printStockLevels` with filtered data, loading state

## Step 6: Update `stock-level-data-table.tsx`

Integrate toolbar into the data table:
- Add `globalFilter` state + `getFilteredRowModel()` to `useReactTable`
- Add `ColumnFiltersState` for advanced filter support
- Accept new props: `onServerSearch`, `onServerSearchClear`
- Render `<StockLevelDataTableToolbar>` above the table
- Pass `table` and props to toolbar

Updated props interface:
```ts
interface StockLevelDataTableProps {
  columns: ColumnDef<StockLevel>[];
  data: StockLevel[];
  onServerSearch?: (filters: StockLevelFilters) => void;
  onServerSearchClear?: () => void;
}
```

## Step 7: Update `page.tsx`

- Add `searchFilters` state for advanced search
- Update `useEffect` to pass filters to `getStockLevels(searchFilters)`
- Pass `onServerSearch` and `onServerSearchClear` to data table
- `onServerSearch`: sets filters → triggers re-fetch
- `onServerSearchClear`: clears filters → triggers re-fetch with no filters
