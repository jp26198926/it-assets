# Plan: Support Pages Auth Redirect + Dynamic App Settings Header

## Summary
Update all `/support` pages to:
1. Redirect logged-in users to `/tickets` automatically
2. Replace hardcoded "IT Support Portal" header with dynamic app settings (name + logo/icon), matching the sidebar pattern

## Files to Modify

### 1. `app/(public)/support/page.tsx` — Landing page

**Auth redirect** — Add a `useEffect` that calls `getCurrentUser()` (from `@/lib/actions/auth-actions`). If a user is returned, redirect to `/tickets` via `router.push()`. Show a loading state while checking.

**Header update** — Replace the hardcoded header:
- Current: `HeadphonesIcon` + `"IT Support Portal"`
- New: Fetch `getAppSettings()` in `useEffect`, display `app_name` (fallback: `"IT Asset Manager"`) + `app_logo` image (if set) or `Server` icon (matching sidebar fallback)

Changes:
- Add imports: `useState, useEffect`, `useRouter`, `getCurrentUser`, `getAppSettings`, `Server`
- Remove `HeadphonesIcon` import
- Add `isLoading` state (default `true`), `appName` state, `appLogo` state
- `useEffect`: call `getCurrentUser()` → if user exists, `router.push("/tickets")`; else set `isLoading` to false
- `useEffect`: call `getAppSettings()` → set `appName` and `appLogo`
- While `isLoading`, render nothing (prevent flash of unauthenticated content)
- Header JSX: `appLogo` ? `<img>` : `<Server>` icon, + `appName` text

### 2. `app/(public)/support/submit/page.tsx` — Submit page

**Auth redirect only** — Same pattern: `useEffect` + `getCurrentUser()` → redirect to `/tickets` if logged in. Add `isLoading` state, render nothing while loading.

No header changes needed (this page only has a "Back to Support Portal" link, no app branding).

### 3. `app/(public)/support/track/page.tsx` — Track page

**Auth redirect only** — Same pattern: `useEffect` + `getCurrentUser()` → redirect to `/tickets` if logged in. Add `isLoading` state, render nothing while loading.

No header changes needed (same as submit — only has a back link).

### 4. `app/(public)/layout.tsx` — Public layout metadata

**Metadata update** — Change hardcoded `title: "IT Support Portal"` to use `generateMetadata()` with `getAppSettings()` for dynamic browser tab title.

Changes:
- Import `getAppSettings` from `@/lib/actions/application-actions`
- Convert to async `generateMetadata()` 
- Return `title: app_name || "IT Asset Manager"`
