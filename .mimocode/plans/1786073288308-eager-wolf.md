# Plan: Add Clone Confirmation Modal with Date/Time Inputs

## Goal
When clicking the Clone button on the meeting detail page, show a confirmation modal with date and time inputs so the user can set the schedule for the cloned meeting before creating it.

## Current State
- Clone button exists in sidebar (added in previous task)
- `cloneMeeting` server action exists but hardcodes the source meeting's date/time
- Need to: (1) create a modal component, (2) update the server action to accept overrides, (3) wire the modal into the page

## Changes

### 1. Create `MeetingCloneModal` component
**File:** `components/modals/meeting-clone-modal.tsx` (new)

Follow the same patterns as `meeting-edit-modal.tsx` and `role-duplicate-modal.tsx`:
- Uses `Dialog`, `DialogContent`, `DialogHeader`, `DialogTitle`, `DialogDescription`, `DialogFooter`
- Form with `id="meeting-clone-form"` and `onSubmit`
- `DialogContent` has `flex flex-col max-h-[85vh]`
- `DialogHeader` has `-mx-4 -mt-4 rounded-t-xl border-b bg-muted/50 p-4`
- Form area has `flex-1 overflow-y-auto min-h-0`
- `DialogFooter` is outside the form, submit button uses `form="meeting-clone-form"`

**Props:**
```ts
interface MeetingCloneModalProps {
  open: boolean;
  onOpenChange: (open: boolean) => void;
  meeting: Meeting | null;
  onConfirm: (data: { scheduled_date: Date; start_time: string; end_time?: string }) => void;
  loading: boolean;
}
```

**Fields (pre-filled from source meeting):**
- Date (`type="date"`) — required, pre-filled with source meeting's `scheduled_date`
- Start Time (`type="time"`) — required, pre-filled with source meeting's `start_time`
- End Time (`type="time"`) — optional, pre-filled with source meeting's `end_time`

**Description text:** `Create a copy of "{meeting.title}" with a new schedule. Minutes and action items will not be copied.`

**Icon:** `Copy` from lucide-react

### 2. Update `cloneMeeting` server action
**File:** `lib/actions/meeting-actions.ts`

Change signature to accept optional date/time overrides:
```ts
export async function cloneMeeting(
  sourceId: string,
  overrides?: { scheduled_date?: Date; start_time?: string; end_time?: string }
): Promise<Meeting>
```

Use overrides when provided, otherwise fall back to source meeting values.

### 3. Update meeting detail page
**File:** `app/(dashboard)/meetings/[id]/page.tsx`

- Import `MeetingCloneModal`
- Add `cloneModalOpen` state (boolean)
- Change `handleClone` to open the modal instead of directly cloning
- Add `handleCloneConfirm` that receives `{ scheduled_date, start_time, end_time }` and calls `cloneMeeting(sourceId, { scheduled_date, start_time, end_time })`
- Render `<MeetingCloneModal>` with the meeting data

**Clone button onClick:** `setCloneModalOpen(true)` (instead of `handleClone`)

## Files to Modify
1. `components/modals/meeting-clone-modal.tsx` — **new file**
2. `lib/actions/meeting-actions.ts` — update `cloneMeeting` signature
3. `app/(dashboard)/meetings/[id]/page.tsx` — wire modal + update handler

## Verification
1. Click Clone button on meeting detail page
2. Modal opens with date/time pre-filled from source meeting
3. Change date/time and click "Clone Meeting"
4. New meeting is created with the selected date/time
5. Navigates to the new meeting detail page
6. Minutes and action items are not copied
