# Add Advanced Search, Advanced Filter, Column Visibility, and Export to Adjustments DataTable

## Context
Same pattern as the conversions module fix. The adjustments toolbar only has a basic text search. Need to add the same 4 features: Advanced Search (with dropdowns for Location and Item), Advanced Filter, Column Visibility, and Export.

## Key Differences from Conversions
- Adjustments have **one item** (not from/to) — `item_id` instead of `from_item_id`/`to_item_id`
- Adjustments have `qty` (single number, can be positive or negative) instead of `from_qty`/`to_qty`
- Adjustments have `date_adjusted` instead of `date_converted`

## Changes

### 1. Update `lib/types/adjustment.ts`
- Add `AdjustmentAdvancedFilter` type:
  ```ts
  export interface AdjustmentAdvancedFilter {
    field: string;
    operator: "contains" | "equals" | "startsWith";
    value: string;
  }
  ```

### 2. Create `components/data-table/adjustment-advanced-search-dialog.tsx` (NEW)
- Fields: Code, Location (dropdown), Item (dropdown), Date From, Date To
- Dropdowns fetch from `getLocations()` and `getItems()` on dialog open
- Shows item name + item_code in dropdown
- Maps to existing `AdjustmentFilters` and `getAdjustments()` service

### 3. Create `components/data-table/adjustment-advanced-filter-dialog.tsx` (NEW)
- Fields: Code, Location Name, Item Name, Remarks
- Operators: Contains, Equals, Starts with
- Client-side filtering via `useMemo` in data table

### 4. Create `components/data-table/adjustment-export-buttons.tsx` (NEW)
- PDF columns: Code, Date, Location, Item, Qty, Remarks
- Excel columns: same + Item Code

### 5. Update `components/data-table/adjustment-data-table.tsx`
- Add `VisibilityState`, `getFilteredRowModel`, `useMemo` imports
- Add `columnVisibility` and `advancedFilters` state
- Add `filteredData` memo
- Pass new props to toolbar

### 6. Update `components/data-table/adjustment-data-table-toolbar.tsx`
- Import and render: `AdjustmentAdvancedSearchDialog`, `AdjustmentAdvancedFilterDialog`, `DataTableViewOptions`, `AdjustmentExportButtons`
- Add `advancedFilters`, `onAdvancedFiltersChange`, `allData` props
- Add `Export` permission check

1. Navigate to `/adjustments`
2. Advanced Search opens with Code, Location dropdown, Item dropdown, Date From, Date To
3. Advanced Filter allows adding/removing conditions on Code, Location, Item, Remarks
